# Projects

## 1. Microservices Communication

Implementation and comparison of microservice communication technologies:

- REST
- gRPC
- GraphQL

### Goals

- Compare communication protocols
- Analyze performance and usability
- Implement equivalent services using different technologies
- Explore modern service-oriented architecture approaches

### Technologies

| Service | Technology |
|---|---|
| REST API | C# / ASP.NET Core |
| gRPC Service | Go |
| GraphQL API | Rust |

### Project Structure

```text

├── rest-service-csharp/

├── graphql-service-rust/
├── docs/
```
